
# JAY COMPUTER ACADEMY

A computer learning portal built with HTML, CSS, JavaScript and Firebase.

## Features

- Student login and registration
- Student dashboard
- Computer course catalogue
- Lesson pages
- Practical task examples
- Basic computer quiz
- Progress tracking
- Certificate preview
- Admin page starter

## Technology

- HTML5
- CSS3
- JavaScript modules
- Firebase Authentication
- Cloud Firestore

## Local development

1. Open this folder in Visual Studio Code.
2. Install the Live Server extension.
3. Open index.html using Live Server.
4. Configure Firebase Authentication and Firestore.
5. Publish secure Firestore Rules before using student accounts.

## Important

New accounts require an approved Firestore user profile.
The current quiz result page uses browser session storage.
The admin management pages are starter pages, not complete management tools.
A certificate must not be treated as verified until course completion and
assessment results are checked securely.
